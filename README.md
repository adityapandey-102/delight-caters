# Delight Caterers

Workspace for the new Delight Caterers platform (delightcaters.in).

| Folder | What it is | Status |
| --- | --- | --- |
| `delight-web/` | Next.js 16 website — Home, About Us, Service, Contact Us, WhatsApp enquiry | Phase 1 |
| `delight-api/` | Express + Drizzle + Supabase API for leads, customers and meal subscriptions | Phase 2 (not started) |

The split mirrors `needleye-pilot` (`needleye-web` + `needleye-api`), so phase 2
can follow the same architecture without moving the website.

See [delight-web/README.md](delight-web/README.md) to run the site.
